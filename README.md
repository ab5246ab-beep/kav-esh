# קו האש

משחק פעולה תלת־ממדי בירושלים, בעברית, למחשב ולטלפון.
יוצאים לרחוב, נוסעים, ויורים רק במחבלים חמושים. פגיעה באזרח או בחטוף עולה בכסף.

## הקישור למשחק
קישור למשחק: https://dove-falcon-star-craft.grok.me

**גישה ישירה:** פותחים את הכתובת הזו, והמשחק נטען מיד. אין הורדה ואין התקנה. כולם נכנסים לאותו קישור. הכסף, הנשקים וההתקדמות נשמרים רק בדפדפן של מי שמשחק באופן פרטי, לא בגיטהאב ולא בחשבון משותף.

הדף הזה שומר את הקוד ואת ההסבר. הוא לא מפעיל את העיר.

## כוכב זה מפרגן

למעלה בדף יש כפתור **Star**. כוכב זה לא כסף, לא פרס ולא מנוי. זה מפרגן: סימן של שנייה שאומר שהמשחק שווה.

בגיטהאב דף בלי כוכבים כמעט לא נמצא. משחק עברי על ירושלים, עם מפה אמיתית ומשימות, נשאר חבוי אם אף אחד לא מסמן אותו. כוכב אחד עוזר למישהו אחר לגלות אותו.

אם שיחקת, אם אהבת שהקוד פתוח לקריאה, או אם בא לך לחזק עבודה בעברית — תן כוכב. זה בחינם, וזה המפרגן הכי ישיר שיש.

## משימות

כל נסיעה במשימה היא עד בערך 800 מטר. החץ הצהוב במפה מראה את הדרך הפנויה, והטקסט למטה אומר מה עושים עכשיו. מעל מחבל יש סימן אדום. אנשים לידו מתכופפים או בורחים. חטוף שנהרג מפיל את המשימה.

| משימה | מה עושים | פרס |
|---|---|---|
| חיסול בתחנה המרכזית | מחסלים את החוטף, בלי לפגוע בחטופים | ₪6,500 |
| חילוץ אוטובוס בגשר המיתרים | מחסלים את השומרים, ואז F ליד האוטובוס | ₪9,000 |
| רכבת עצורה בשער שכם | אפשר לירות בחוטפים, ו־F ליד כל נוסע לפני שהרכבת זזה | ₪11,000 |
| הגמר בספורטק | מחנים שני אוטובוסים בעיגולים הצהובים, ואז מחסלים את היורה מול היציע | ₪14,000 |

חיסול מחבל חמוש בסיור נותן ₪400.

## מה יש בקוד

המשחק כתוב ב־TypeScript, עם React למסך ו־Three.js לעיר.

| קובץ | תפקיד |
|---|---|
| `src/game/engine.ts` | הלולאה: הליכה, רכב, ירי, משימות, גלים |
| `src/game/city.ts` | העיר: כבישים, אתרים, ספורטק, תחנה, גשר |
| `src/game/osm-layout.ts` | נקודות המפה שיובאו מ־OpenStreetMap |
| `src/game/route.ts` | החץ הצהוב: מסלול על הכביש, בלי לחתוך בניינים |
| `src/game/catalog.ts` | נשקים, רכבים, פרסי המשימות, טקסט המשימות |
| `src/game/world.ts` | נקודות יעד: תחנה, גשר, רכבת, ספורטק |
| `src/game/meshes.ts` | דמויות ורכבים. למחבל יש רובה וסימן אדום |
| `src/components/game-app.tsx` | המסך בעברית: כסף, משימה, כפתורים |
| `src/styles.css` | העיצוב |

שתי שיטות השליטה נשמרות במכשיר (`kav-esh-play`: `pc` או `touch`). אין ערבוב בין גה של רכב לבין הליכה.
.

## להרצה מקומית

צריך Node.js. מתוך התיקייה:

```bash
npm install
npm run dev
```

השרת המקומי עולה על פורט 8080. זה עותק להרצה אצלך. הקישור הציבורי למשחק נשאר הכתובת שמסתיימת ב־`grok.me`.
